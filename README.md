# כוכב התנ״ך — демо ремейка игры «חן התנ״ך»

Один самодостаточный файл **`dist/chen-hatanach-millionaire.html`** (~1.2 МБ): двойной щелчок — и игра работает
полностью офлайн. Шрифты, графика, звуки, SheetJS для Excel — всё внутри файла; строгий CSP запрещает любые
сетевые запросы. Онлайн-копия демо (noindex): https://chen-hatanach.kikkey.com

## Что внутри
- Сцена 1920×1080 с letterbox под любое окно (проверено 1920×1080, 1366×768, 16:10, 5:4, 21:9, 4K, телефон).
- Иврит RTL; шрифты Noto Serif Hebrew (вопросы/ответы с никудом), Frank Ruhl Libre (заголовки), Rubik (интерфейс).
- Заставка → «לוח הכוורות» (соты-шестиугольники, лидерборд с короной) → экран כוורת (пустые доски + PLAY) →
  вопрос по словам, 4 ответа (Fisher–Yates), фиксация 1,5 с, раскрытие, «+6» в счётчик, старец лезет по дереву,
  50:50 (растворение, очки пополам), таймер ответа, источник стиха → результат (венок, конфетти) → BACK.
- Админка (шестерёнка): настройки (название, уровень, число כוורות, 1/4/10 вопросов, очки, 50:50, таймер, тема
  «модерн / классика со скайлайном Иерусалима», логотипы), אוספי שאלות, таблица с редактированием на месте,
  импорт Excel/CSV/JSON (xlsx, xls, csv utf-8/utf-16/cp1255) с предпросмотром и поиском дублей, шаблон Excel,
  экспорт JSON, карточка DataMil.xml «בגרסה המלאה», восстановление демо-вопросов.
- Синтезированные звуки (WebAudio), частицы на canvas, авто-режим «облегчённых эффектов» для слабых ноутбуков.
- Состояние раунда в localStorage (любое обращение в try/catch; без него игра тоже работает), продолжение после перезагрузки.

## Управление ведущего
| Клавиша | Действие |
|---|---|
| Пробел / Enter | START · PLAY · следующий вопрос |
| 1 – 4 | выбрать ответ א׳–ד׳ |
| H | 50:50 |
| Esc | назад (в полноэкранном режиме выход — долгое нажатие Esc) |
| F | полный экран |
| M | звук вкл/выкл |
| ? | подсказка по клавишам |

На поле כוורות можно набрать номер цифрами и нажать Enter (или стрелки). Клик по сыгравшей (серой) כוורת
предлагает открыть её заново. Админка — шестерёнка в левом нижнем углу или `#admin` в адресе.
`?fx=full` / `?fx=low` принудительно включают полный / облегчённый режим эффектов.

## Сборка и проверки
```bash
node build.mjs                        # → dist/chen-hatanach-millionaire.html
node tests/e2e.mjs dev/shots          # 2 כוורות + 24×10 + продолжение + таймер + тема; скриншоты 1920/1366; консоль и сеть
node tests/regress.mjs                # регрессия: защита незаконченной כוורת, диалоги, таймер под окнами, результат
node tests/fixtures/make-fixtures.mjs # тестовые файлы импорта (xlsx на 20 вопросов, csv cp1255, json)
cd deploy && npm run deploy           # публикация на Cloudflare (Worker со static assets)
```
Настоящие логотипы: положите `chen-hatanach-wordmark.png` и `chen-hatanach-emblem.png` в `src/assets/brand/`
и пересоберите — они заменят векторные реконструкции (их также можно загрузить в админке).

## Известные ограничения демо
- Логотип и эмблема — векторные реконструкции по описанию (оригинальные PNG подставляются без правки кода).
- Шрифт Noto Serif Hebrew ставит хирик поверх патаха в «יְרוּשָׁלִַם» (двойная огласовка) — в полной версии
  подключим шрифт с правильной укладкой знаков (например, Taamey Frank CLM / Ezra SIL).
- Звуки отлажены по спектрограммам; на реальных колонках проектора стоит прослушать и подстроить громкость.

## Структура
`src/js/*.js` — модули (по одному `<script>` в файле, общий объект `window.CH`), `src/css/*.css`, шрифты в
`src/assets/fonts` (SIL OFL), SheetJS CE (core) в `src/vendor`. Контракт модулей — `docs/ARCHITECTURE.md`.
