# כוכב התנ״ך — демо ремейка игры «חן התנ״ך»

Один самодостаточный файл **`dist/chen-hatanach-millionaire.html`**: двойной щелчок — и игра работает
полностью офлайн (шрифты, графика, звуки, SheetJS для Excel — всё внутри файла; CSP запрещает любые сетевые запросы).

## Управление ведущего
| Клавиша | Действие |
|---|---|
| Пробел / Enter | START · PLAY · следующий вопрос |
| 1 – 4 | выбрать ответ א׳–ד׳ |
| H | 50:50 |
| Esc | назад |
| F | полный экран |
| M | звук вкл/выкл |
| ? | подсказка по клавишам |

На поле участников можно набрать номер участника цифрами и нажать Enter, правый клик по сыгравшей плитке
снимает блокировку. Админка — шестерёнка в левом нижнем углу (или `#admin` в адресе).

## Сборка
```bash
node build.mjs                        # → dist/chen-hatanach-millionaire.html
node tests/e2e.mjs dev/shots          # полный прогон 2 участников + 24×10, скриншоты 1920/1366, проверка консоли и сети
node tests/fixtures/make-fixtures.mjs # тестовые файлы импорта (xlsx на 20 вопросов, csv cp1255, json)
```
Настоящие логотипы: положите `chen-hatanach-wordmark.png` и `chen-hatanach-emblem.png` в `src/assets/brand/`
и пересоберите — они заменят векторные реконструкции. Их также можно загрузить прямо в админке.

## Структура
`src/js/*.js` — модули (по одному `<script>` в файле, общий объект `window.CH`), `src/css/*.css`, шрифты в
`src/assets/fonts` (Noto Serif Hebrew, Frank Ruhl Libre, Rubik — SIL OFL), SheetJS CE в `src/vendor`.
Контракт модулей — `docs/ARCHITECTURE.md`.
